本ポリシーは、個人用アプリ「振り返りメモ連携」によるGoogleユーザーデータの取り扱いについて説明します。運用者はGitHubアカウント yu0409ta-bit の管理者です。

1. 利用目的

Google ToDoに記録した、管理者本人のやりたいこと・やるべきことをNotionに取り込み、整理・振り返りに利用することを目的とします。

2. アクセス・取得する情報

本人が認証したGoogleアカウントのGoogle Tasks APIから、リスト名と識別子、タスクのタイトル・詳細・識別子・完了状態・予定日・完了日時・更新日時・タスクへのリンクなど、連携に必要な情報を取得します。完了済み項目も取り込み対象です。

要求する権限はGoogle Tasks APIの読み取り専用権限です。Google側への追加・更新・削除は行いません。Googleアカウントのログインパスワードは取得しません。Gmail本文やDriveのファイルへのアクセス権限は要求しません。

3. 保存先と利用するサービス

取得したタスク情報は、本人のNotionワークスペース内の専用データベースに保存します。取得・同期の処理にはNotion Workersを使用します。Googleとの認証に必要な情報はNotion Workersの認証・シークレット管理機能を用いて扱い、この公開サイトや公開リポジトリに掲載しません。

本アプリは、GoogleからNotionへの一方向の取り込みを行います。本人がNotion AIに整理や振り返りを依頼した場合は、その操作とNotion側の設定・規約に従って情報が処理されます。Notion AIの自動実行は本連携に含まれません。

4. データの共有と利用制限

連携処理のために利用するGoogleおよびNotionを除き、運用者が取得データを広告・販売目的で第三者に提供することはありません。Notion内の閲覧範囲は本人の共有設定に従います。本人のGoogleユーザーデータは、このアプリの公開サイトには掲載しません。

Google APIから受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（Limited Useの要件を含む）に従います。

5. 保管期間と削除

Notionに取り込んだデータは、本人が必要とする期間保管します。データの削除やワークスペースの整理は、本人がNotion上の管理機能および連携の管理操作で行います。Google側でアクセス許可を取り消すだけでは、すでにNotionへ保存したデータは自動削除されません。

6. アクセス許可の取り消し

Googleアカウントのサードパーティとの接続から、本アプリへのアクセス許可を取り消せます。取り消し後は新たな取得ができなくなります。定期同期の停止や認証情報の削除は、Notion側の連携管理機能で行います。

7. この公開サイトについて

この説明サイトはGitHub Pagesで公開します。本サイト独自のアクセス解析、広告、入力フォームは設置していません。配信に伴うアクセス情報などの取り扱いは、GitHubのプライバシーに関する声明にも従います。

8. お問い合わせ・変更

お問い合わせには、GoogleのOAuth同意画面に表示されるユーザーサポートメールアドレスをご利用ください。データの取り扱いを変更する場合は、本ページの内容と最終更新日を更新します。
